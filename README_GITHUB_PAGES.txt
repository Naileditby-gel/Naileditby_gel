NAILEDITBY_GEL — GitHub Pages

This folder is ready to publish as a static GitHub Pages site.

Files to publish:
- index.html
- admin.html
- config.js

The SQL files are setup/reference files and do not need to be published for the website to work. They can remain in the repository, but remember that GitHub Pages repositories are public on GitHub Free.

GitHub Pages setup:
1. Create a public repository on GitHub.
2. Upload index.html, admin.html, and config.js to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for deployment and open the URL GitHub gives you.

Do not put any Supabase service-role/secret key, password, OTP, or GCash credentials in this repository.
